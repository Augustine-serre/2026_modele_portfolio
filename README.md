# README - Modèle de portfolio

Ce dépôt fournit un modèle de site web prêt à l’emploi pour les étudiant·e·x·s.

L’objectif est simple : vous permettre de créer rapidement un site web propre, structuré et personnalisable, sans connaissances avancées en programmation. Le contenu de ce site web devra être personnalisé et constituera votre rendu final du projet individuel.

## Structure du dépôt
```
├── content
│   ├── apropos.md
│   ├── portfolio.md
│   ├── project.ipynb
│   └── img
│      └── ma_photo.png
```

Plus d'informations concernant l'utilisation de ce dépôt sont disponibles dans l'[étape II du projet](https://gse-unil.github.io/2026_Geoinformatique_II/project/etape2/).
