# README - Modèle de portfolio

Ce répertoire fournit un modèle de portfolio prêt à l’emploi pour les étudiant·e·x·s.

L’objectif est simple : vous permettre de créer rapidement un site web contenant un portfolio propre, structuré et personnalisable, sans connaissances avancées en programmation. Le contenu de ce portfolio devra être personnalisé et constituera votre rendu final du projet individuel.

## Structure du répertoire
```
├── content
│   ├── apropos.md
│   ├── portfolio.md
│   ├── project.ipynb
│   ├── rapport_final.md
│   └── img
│      └── ma_photo.png
```

Plus d'informations concernant l'utilisation de ce répertoire sont disponibles dans l'[étape II du projet](https://gse-unil.github.io/2026_Geoinformatique_II/project/etape2/).
